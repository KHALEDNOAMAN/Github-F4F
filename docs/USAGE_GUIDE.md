# GitHub F4F CLI - Usage Guide

## Commands
| Command | Description |
|---------|------------|
| f4f check | See who doesn't follow back |
| f4f unfollow | Unfollow non-followers |
| f4f whitelist add user | Protect user from unfollow |
| f4f stats | Show follow statistics |
| f4f dry-run | Preview without changes |

## Best Practices
- Always run dry-run first
- Add important accounts to whitelist
- Don't mass-unfollow (GitHub may flag)
- Use rate limiting between actions
